# Deployment

`vercel.json` and `render.yaml` provide starter hosting configuration for Vercel (web) and Render (API). Configure `VITE_API_URL` for the web app and `WEB_ORIGIN`, `MONGODB_URI`, and optionally `GEMINI_API_KEY` for the API. Keep secrets in provider environment settings and configure strict production CORS. The API deliberately returns HTTP 503 for `/api/v1/*` when `NODE_ENV=production` because real authentication and durable user-scoped repositories are not implemented; remove this guard only after those are implemented and reviewed. MongoDB currently serves as a seed target and connection health signal, while API demo reads/actions remain in process memory. Configure MongoDB Atlas network access narrowly. `/health` is a smoke-test endpoint. Rollback by restoring the prior frontend and API deployment; retain database backups and schema compatibility. No deployment has been performed or verified.
