# Costs and external services

No paid resources are provisioned by this project. Text demo mode has no AI provider cost. Gemini Live calls require a user-configured key and may incur usage charges under that account. Check the current official [Gemini API pricing](https://ai.google.dev/gemini-api/docs/pricing) and quotas before enabling. MongoDB Atlas, Render, and Vercel costs depend on plans and usage; this repository creates no accounts or paid resources.
