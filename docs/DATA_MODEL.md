# Data model

The local synthetic domain includes user, transaction, merchant/category, subscription candidate, bill, EMI schedule, reminder, spending alert, agent action, and audit event. Each record is scoped by `ownerId`. Amounts are integer paise, dates ISO timestamps, currency INR, and seeded transaction generation is deterministic for a supplied date. The canonical local fixture is in `apps/api/src/data/seed.js`; `npm run seed` writes synthetic transactions to MongoDB. The API reads through an async, owner-scoped store interface (`apps/api/src/store/memory.js`); the in-memory implementation keeps action state in process memory, and a MongoDB implementation of the same interface is the intended path to durability; Mongo-backed runtime repositories and durable action history remain future work. No real financial record is required or accepted by the demo.
